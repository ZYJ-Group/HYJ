# 卫星 ISAR 图像未见 GSD 泛化与少样本/零样本方法实验进展

## 一、本周主要工作

本周根据导师提出的“参考少样本学习或零样本学习方法优化库外 GSD 估计”的建议，
重新整理了任务定义，并建立了独立的 `11.3` 连续尺度泛化工程。在不改变 SiConv
主干网络的前提下，分别复现和适配了 Balanced MSE、Rank-N-Contrast（RNC）与
MLDG 三类方法，用于研究训练尺度不均衡、连续尺度表征不充分以及未见尺度域偏移
三个问题。

### 1. 明确当前任务与经典少样本、零样本任务的区别

当前训练集包含 GSD=0.05、0.10、0.20、0.25，测试集中的库外尺度为
GSD=0.15。训练、验证和超参数选择都不使用任何 0.15 标签。因此当前任务更准确的
定义是：

> 连续标签空间中的未见尺度泛化，或零目标标注的持出尺度泛化。

它与经典零样本分类有所不同。经典零样本分类通常通过类别属性、文本描述或语义
向量识别未见类别，而本项目的 GSD 是连续物理量，不存在“0.15类别文本描述”可以
直接使用。

它也不是目前就能合理开展的 K-shot 微调任务。因为现有库外测试集中所有样本的
真实 GSD 都是0.15，如果给模型一张带标签的库外图片，模型就已经知道整个目标域
的唯一答案是0.15，直接输出常数也可能获得很高准确率。这种实验无法证明模型学会
了图像尺度估计。因此，本周首先借鉴少样本与元学习中的度量表征、虚拟任务划分和
域外泛化思想，在完全不使用0.15标签的条件下提高泛化能力。

### 2. 建立严格 group-disjoint 数据协议

过去的历史划分虽然将0.15从训练集中移除，但相同的 `卫星类别+姿态+时刻` 可能
同时出现在训练集和测试集，模型可能记住相同目标状态。为降低这种数据泄漏，本周
使用 `group_key` 重新划分数据，使训练、验证、库内测试和库外测试的目标状态组
完全互斥。

| 划分 | 样本数 | 状态组数 | GSD |
|---|---:|---:|---|
| train | 1419 | 470 | 0.05、0.10、0.20、0.25 |
| val | 335 | 109 | 0.05、0.10、0.20、0.25 |
| test_seen（库内） | 420 | 144 | 0.05、0.10、0.20、0.25 |
| test_unseen（库外） | 144 | 144 | 0.15 |

训练集中各尺度样本数并不均衡：0.05和0.10各有470张，0.20有294张，0.25只有
185张。这为 Balanced MSE 的标签分布校正提供了实际动机。

严格协议下的库外测试不仅要求模型预测未见过的0.15，还要求模型处理训练中未出现
过的目标状态组合，因此明显难于历史协议。后续周报和论文中应分别标注“历史协议”
与“严格分组协议”，不能直接把两套准确率放在同一列排名。

![实验协议与训练数据分布](figures/weekly_2026-11-02/01_protocol_and_distribution.png)

图1展示了严格分组协议和训练尺度分布。一方面，四个划分的状态组完全互斥；另一
方面，训练集中0.05、0.10样本明显多于0.20、0.25，这说明当前任务同时存在目标
状态泛化和连续标签不均衡两个问题。

### 3. 建立统一的 SiConv 连续回归基线

为了单独判断训练方法是否有效，本周模型只保留：

```text
ISAR图像
  → SiConv共享核多尺度卷积
  → ResNet-18编码器
  → 512维共享特征
  → log-GSD回归头
  → 连续GSD预测
```

SiConv 保留了9.16版本中的尺度坐标归一化、64维尺度嵌入和可学习 `scale_gate`。
本阶段没有加入关键点、几何、热图、时序、CLISAR、ADRISAR或PCGrad，保证不同
实验只改变训练目标，不改变推理结构。

本周的第一轮筛选实验只使用上述单回归头结构，目的是低成本判断损失函数和表征约束
是否有价值。筛选出有效方向后，下一阶段不会继续停留在单回归头，而是将BMC、RNC
和MLDG迁移回原来的完整多任务几何模型。

![完整多任务几何模型与未见GSD泛化方法适配框架](figures/weekly_2026-11-02/07_full_model_fewshot_framework.png)

图2给出了下一阶段的完整适配方案。完整模型保留GSD回归、GSD分类、关键点热图、
横向分辨率热图、卫星类别和姿态辅助分支；关键点经过面板校正、PCA及长短轴计算后
形成几何GSD；网络回归、热图尺度和几何尺度最后通过可靠性模块融合。RNC作用于共享
特征空间，BMC替换或混合回归损失，MLDG通过轮流持出源GSD模拟库外域。该图是下一
阶段方案，不代表完整模型已经完成本轮实测。

普通基线采用 ERM（Empirical Risk Minimization），即在所有训练样本上最小化
预测 log-GSD 与真实 log-GSD 之间的 Smooth L1 损失。使用 log-GSD 是因为模型
需要学习的是相对尺度变化，例如0.05到0.10与0.10到0.20都是放大一倍，在对数空间
中的距离更符合这种比例关系。

## 二、参考论文与方法原理

### 1. Balanced MSE：校正连续标签分布不均衡

参考论文：Jiawei Ren等，**Balanced MSE for Imbalanced Visual Regression**，
CVPR 2022。

- 论文：<https://openaccess.thecvf.com/content/CVPR2022/html/Ren_Balanced_MSE_for_Imbalanced_Visual_Regression_CVPR_2022_paper.html>
- 官方代码：<https://github.com/jiawei-ren/BalancedMSE>

普通 MSE 或 Smooth L1 默认训练数据能够代表测试数据分布。如果某些连续标签出现
次数更多，模型会优先拟合高频区域。例如当前0.05和0.10样本明显多于0.25，模型
可能更多地学习小GSD样本的统计规律，预测结果也容易向高频尺度偏移。

Balanced MSE 从概率角度重新解释回归损失：普通 MSE 等价于让模型拟合训练分布
下的条件概率，但训练标签先验并不均匀；Balanced MSE在损失中补偿这种标签先验，
使模型更接近在均衡标签分布下进行预测。它不是简单地给少数尺度乘一个固定权重，
而是在预测分布中同时考虑当前样本与其他候选标签之间的相对概率。

本项目采用论文提出的一维 Batch Monte-Carlo（BMC）形式。对一个 batch 中第 i 个
预测值，所有 batch 标签都作为候选，正确标签是第 i 个标签。预测与候选标签越接近，
对应的高斯相似度越高，再通过交叉熵要求正确标签的相对概率最大：

```text
logit(i,j) = -(预测_i - 标签_j)² / (2σ²)
```

其中 σ 表示回归噪声尺度，本项目将其设置为可学习参数，并使用 softplus 保证 σ
始终为正。BMC主要解决“源GSD样本数量不均衡”，但它不能直接生成训练中完全缺失
的0.15信息，因此它更适合作为低成本损失基线。

### 2. Rank-N-Contrast：让特征空间保持连续尺度顺序

参考论文：Kaiwen Zha等，**Rank-N-Contrast: Learning Continuous
Representations for Regression**，NeurIPS 2023。

- 论文：<https://proceedings.neurips.cc/paper_files/paper/2023/hash/39e9c5913c970e3e49c2df629daff636-Abstract-Conference.html>
- 官方代码：<https://github.com/kaiwenzha/Rank-N-Contrast>

普通回归只要求每个样本最终预测接近真值，并不保证中间特征按照连续标签有序排列。
因此，0.05、0.10、0.20、0.25的特征可能分散成几个互不连续的簇，模型在0.10和
0.20之间遇到未见0.15时就不容易进行合理插值。

RNC根据连续标签距离建立排序对比关系。以GSD=0.10样本为锚点，0.05和0.10之间
的标签距离小于0.10和0.25之间的距离，因此前者的特征应更接近锚点，后者应更远。
它不是只把“同标签”定义为正样本，而是要求特征距离的顺序与标签距离的顺序一致。

理想情况下，模型形成如下连续特征结构：

```text
0.05 —— 0.10 —— 0.15 —— 0.20 —— 0.25
```

虽然训练中没有0.15，但如果0.10和0.20之间的特征空间连续，回归头更可能在中间
位置输出0.15。本项目在SiConv的512维特征后增加128维投影头，使用两种图像增强
构成同一样本的两视图，并采用：

```text
总损失 = log-GSD Smooth L1 + 0.05 × RNC损失
```

投影头只在训练时使用，推理阶段仍然只有原GSD回归头，因此RNC不会增加最终部署
结构。训练batch使用GSD均衡采样，保证每个batch至少出现三个不同源GSD，否则
无法建立有效的连续排序关系。

### 3. MLDG：在训练阶段反复模拟“未见尺度”

参考论文：Da Li等，**Learning to Generalize: Meta-Learning for Domain
Generalization**，AAAI 2018。

- 论文：<https://ojs.aaai.org/index.php/AAAI/article/view/11596>
- 作者代码：<https://github.com/HAHA-DL/MLDG>

MLDG关注域泛化问题：测试域在训练阶段完全不可见，模型需要只利用多个源域学习
能够迁移到新域的参数。它的核心思路是在训练过程中人为制造域偏移，把一部分源域
作为虚拟训练域，把另一部分作为虚拟测试域。

本项目把不同源GSD看作不同尺度域：

```text
源域 = {0.05, 0.10, 0.20, 0.25}
```

每一步从当前batch中轮流选择一个GSD作为 `meta-test`，其余GSD作为
`meta-train`。例如：

```text
meta-train = {0.05, 0.10, 0.25}
meta-test  = {0.20}
```

模型先在 `meta-train` 上计算一次临时更新，再使用临时参数预测 `meta-test`。
训练目标不仅要求当前源域误差小，还要求“在部分尺度上更新之后，另一个被持出尺度
的误差也下降”。这样每个源GSD都反复扮演虚拟未见域，训练过程持续模拟最终遇到
0.15的情况。

本项目第一版采用一阶MLDG，临时更新只适配GSD回归头和编码器最后一层，避免完整
二阶梯度带来的显存和数值问题：

```text
L_MLDG = L_meta-train + 0.5 × L_meta-test
```

同时实现了 `RNC+MLDG`：RNC负责建立连续有序的尺度表征，MLDG负责模拟源域到
未见域的分布变化。两者理论上解决不同问题，但是否互补仍需通过实验验证。

## 三、阶段性诊断结果与相对收益

本周已经完成 seed=42 的 ERM、Balanced MSE和RNC实验，训练轮数均为80，
Backbone、数据增强、batch size和模型选择方式保持一致。

需要特别说明：本轮实验的目的不是取代历史完整模型，而是用严格协议和简化单回归头
筛选值得迁移的训练方法。历史结果与当前结果的实验含义不同：

| 对比项 | 历史完整SiConv实验 | 本周严格诊断实验 |
|---|---|---|
| 模型结构 | 多任务、关键点、热图、几何与融合 | SiConv编码器＋单GSD回归头 |
| 数据划分 | 历史划分 | 状态组完全互斥的group-disjoint划分 |
| 主要目的 | 获得完整系统性能 | 判断BMC、RNC等方法是否值得迁移 |
| 库外表现 | 历史记录曾达到80%以上，准确值需以原summary核验 | 当前严格协议下进行方法筛选 |

从“方法是否带来改善”的角度看，BMC是本轮最明确的有效方向：相对ERM，库外准确率
提高16.67个百分点，库外MAE降低18.87%，RMSE降低12.18%，绝对Bias缩小约
52.34%。因此本周应汇报为“BMC验证了均衡回归损失对未见尺度有帮助”，而不是把
简化模型的绝对准确率当作最终系统上限。

![BMC相对ERM的阶段性收益](figures/weekly_2026-11-02/08_bmc_relative_gain.png)

图3使用相对改善量概括本周的主要发现。所有数值均来自seed42真实结果；其中准确率
采用百分点，其余指标采用相对下降比例。完整多任务模型迁移后的最终准确率仍需重新
训练获得。

|---|---:|---:|---:|---:|---:|---:|---:|

| SiConv + BMC | 0.01518 | 80.71% | 0.01517 | **45.83%** | **0.02700** | **0.03225** | **-0.00959** |

图4进一步比较MAE与RMSE。BMC的库内MAE最大，但库外MAE和RMSE最低；RNC与
ERM的库内误差接近，库外误差也仅有小幅差异。这与准确率结果相互印证。

![三种方法的库外系统性偏差](figures/weekly_2026-11-02/05_unseen_bias.png)

图5表明三种方法的库外Bias均为负，即都倾向于把真实GSD=0.15预测得偏小。BMC
的Bias最接近0，说明其库外收益主要来自缓解系统性低估，而不是简单增加随机波动。

相对ERM：

- BMC的库外准确率提高16.67个百分点，库外MAE降低约18.87%，RMSE降低约
  12.18%；
- BMC将库外负偏差从-0.02012缩小到-0.00959，说明它明显缓解了对0.15的
  系统性低估；
- 但BMC的库内准确率下降14.29个百分点，库内MAE增加超过一倍，说明当前BMC
  在泛化能力与已见尺度精度之间产生了明显交换；
- RNC的库内结果略优于ERM，验证集MAE下降约4.33%，但库外MAE只下降约1.25%，
  单独使用RNC尚未带来明显的未见尺度提升。

## 四、阶段性分析

1. 当前结果证明严格分组协议明显难于历史协议。过去原版SiConv的库外准确率可达
   80%以上，但历史测试集有722张，并且相同目标状态可能跨训练和测试重复；本次
   严格测试集只有144张，每个库外样本都属于独立目标状态组。此外，本次模型只保留
   单一回归头，没有使用原模型的关键点、几何、热图和多任务融合，因此两套结果不
   能直接比较。

2. BMC是目前最有明显库外收益的方法。训练集中0.05和0.10样本更多，BMC降低了
   模型向高频、小GSD区域偏移的趋势，因此0.15预测偏差明显减小。但它同时破坏了
   源尺度拟合，说明当前可学习噪声尺度或损失强度还没有兼顾库内与库外性能。

3. RNC目前更像一种温和的表征正则。它改善了验证集和库内结果，说明连续排序约束
   没有破坏原模型，但库外提升有限。可能原因包括源GSD只有四档、每档内部图像变化
   较大，以及RNC权重0.05较小。由于已经查看0.15测试结果，后续不能依据库外结果
   直接调整RNC权重，必须使用源GSD轮流持出验证进行选择。

当前仍未出现同时支配库内与库外指标的方法：ERM与RNC偏向库内拟合，BMC偏向库外
泛化。下一阶段的关键不是继续在简化回归头上追求表面准确率，而是把BMC的均衡作用
迁移到完整几何模型中，同时由可靠性融合保留原模型的库内优势。

4. 当前实验还不能直接称为“少样本GSD估计”。本周实际完成的是借鉴连续度量学习、
   不平衡回归和元学习思想的零目标标注尺度泛化。真正K-shot实验需要新的目标域协议，
   使支持集和查询集都包含多个GSD，并按目标状态组隔离，否则少量0.15标签会直接
   泄露答案。

5. 为判断29.17%的严格ERM基线下降来自数据协议还是模型简化，已经确认严格CSV
   保留完整关键点、类别和姿态字段。下一步可以把原版完整多任务SiConv放到同一严格
   划分下运行一次。若完整模型仍明显下降，说明历史80%以上结果受划分重叠影响较大；
   若完整模型恢复较高准确率，则说明几何和多任务分支确实提供了重要信息。

## 五、下一步计划

1. 在相同严格划分下运行原版完整SiConv seed42，建立“单回归头SiConv”和“完整
   多任务SiConv”的公平对照，分离数据协议与模型结构的影响。
2. 完成 MLDG 和 RNC+MLDG 的 seed42 实验，与ERM、BMC、RNC形成五种方法对比。
3. 使用源GSD伪持出交叉验证评估方法稳定性：轮流持出0.05、0.10、0.20、0.25，
   不再使用0.15结果调整超参数。
4. 如果BMC在源GSD持出验证中仍稳定改善，研究BMC与Smooth L1的混合损失或较温和
   的校正方式，重点解决库内性能下降问题。
5. 从五种方法中选择一到两个候选补充 seed43、seed44，报告均值、标准差和配对
   差值；不对全部方法盲目进行三种子训练。
6. 后续若构造出含多个GSD的新目标域，再开展1-shot、5-shot和10-shot适配；当前
   仍以零目标标注的未见尺度泛化作为主实验。

## 六、本周总结

本周完成了少样本/零样本方向的任务定义、严格 group-disjoint 数据划分、独立
`11.3`工程和三种训练方法的第一轮实验。当前任务应表述为连续GSD的零目标标注
持出尺度泛化，而不是经典零样本分类。

本轮严格诊断实验中，BMC相对ERM将库外准确率提高16.67个百分点，MAE降低
18.87%，RMSE降低12.18%，并将绝对Bias缩小约52.34%，是当前最值得迁移到
完整模型的方向；RNC能够保持较好的库内表征，但库外增益有限。当前绝对准确率来自
