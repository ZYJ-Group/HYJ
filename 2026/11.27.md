# 卫星 ISAR 图像未见 GSD 估计：对比实验与模型研究进展



近期在上期四种模型、单随机种子对比的基础上，补充 LISE 和 LEVIRDet-GSD，将正式实验扩展至五种对比方法与本方法、三个随机种子，共 18 个模型运行；完成六种消融配置在四个源尺度上的 24 组留一实验，以及卫星类别分层、统计检验和计算效率分析。同时对现有网络的实际信息流、跨尺度图像结构和关键点几何一致性开展研究。**本期正式汇报继续使用已完成验证的 9.16 Original 模型（11.9 V3 Canonical 实验协议）；新模型尚在研究中，不将其列入正式性能对比。**

## 一、横向对比实验

### 1. 实验设置

目标是仅根据卫星 ISAR 图像估计连续 GSD，重点考察模型对训练中未出现的中间尺度 0.15 m/px 的估计能力。以卫星类别、姿态、时刻构成状态组，训练、验证与测试按状态组隔离。Seen 与 Unseen 测试集共享 144 个测试状态组，便于比较相近目标状态在不同尺度下的表现。

| 数据集 | 图像数 | 状态组数 | GSD（m/px） |
|---|---:|---:|---|
| Train | 1419 | 470 | 0.05 / 0.10 / 0.20 / 0.25 |
| Validation | 335 | 109 | 0.05 / 0.10 / 0.20 / 0.25 |
| Test Seen | 420 | 144 | 0.05 / 0.10 / 0.20 / 0.25 |
| Test Unseen | 144 | 144 | 0.15 |

正式实验采用 seed 42、43、44，报告独立训练种子的均值与标准差。MAE、RMSE 以 m/px 为单位；P90 为绝对误差的第 90 百分位数；五档准确率由连续预测映射至最近的预设档位后计算。各方法共用数据划分与评价口径，保留各自输入预处理、训练策略和监督机制，因此属于完整方法比较。

| 对比方法 | 主要原理及本项目实现 |
|---|---|
| ResNet18 Regression | 通用 CNN 全局特征直接回归 GSD。 |
| Regression Tree CNN（adapted） | 基于浮点指数与尾数思想的部分适配，并非完整 Binomial Tree 路由复现。 |
| PatchMSDNet（adapted） | 局部图像块采样、多尺度方向卷积与轻量化特征融合；根据公开结构独立实现。 |
| LISE 2021 FIX2（新增） | 基于官方源码移植，采用 MobileNetV2、五块灰度图像裁剪和 MAPE 损失。将内部目标由 px/cm 等价转换为 px/m，解决小量纲造成的训练数值发散，最终统一输出 m/px。 |
| LEVIRDet-GSD scratch（新增） | 适配原方法的在线 GSD 估计分支，结合 CNN、频域与边缘特征及注意力机制，从随机初始化训练。 |
| 本方法（9.16 Original） | 多任务尺度监督与预测关键点、卫星类别、姿态等结构条件联合回归。 |

五种外部方法中，四种有对应的独立论文来源，ResNet18 为通用架构基线。尚无法核实外部预训练尺度覆盖范围的 LEVIRDet 预训练版本不进入严格主表。历史 SiConv 实验采用不同划分协议，也不直接混入本轮排名。

**结果分析：**

- 本方法在未见 0.15 m/px 上获得最低平均 MAE、RMSE、P90 及最高最近档准确率（数值点估计）。相较 PatchMSDNet，平均 MAE 降低约 2.97%，P90 降低约 11.63%，五档准确率提高 3.47 个百分点。相较直接回归 ResNet18，Unseen MAE 降低约 68.50%。
- ResNet18 与 Regression Tree 在 Seen 上误差很低，但 Unseen 偏向较大的训练档位，表明训练档拟合不能代替未见中间尺度估计。LISE 与 LEVIRDet 的表现居中。
- PatchMSDNet 与本方法在 Unseen 上表现接近，且 PatchMSDNet 的 Seen/Unseen MAE 更均衡、参数更少。不能将本方法的数值优势表述为统计显著优势。上期表格中本方法 seed42 的五档准确率更正为 114/144=79.17%，与上期正文一致。

## 二、当前网络框架及消融实验

### 1. 9.16 多任务—几何条件 GSD 估计网络

![当前9.16模型网络框架](./figures/02_model_architecture.png)

**图 2.** 基于 9.16/V3 实际源码审查重绘的结构示意图。实线为正式连续 GSD 输出所需的信息流，虚线表示辅助分支；不是待研究的新网络，也不表示使用 GT 进行最终预测。

本方法使用 224×224 RGB 图像，通过共享 ResNet18 提取全局和空间特征。全局特征分别投影为尺度表征与几何条件表征；空间特征用于预测关键点热图及横向尺度辅助热图。

| 模块 | 输入、处理与输出 |
|---|---|
| 共享特征提取 | 224×224 RGB 图像，提取 512 维全局特征和空间特征图。 |
| 尺度分支 | 256 维 `f_scale`；通过连续回归、五档分类、有序分类等任务监督，并通过 GRL 探索尺度表征与姿态信息的解耦。 |
| 卫星与姿态条件 | 从 256 维 `f_geo` 预测 2 维卫星类别概率、36 维姿态概率。 |
| 关键点分支 | 空间特征预测 8×64×64 热图，经 Soft-Argmax 得到 8 个二维关键点。 |
| 面板几何统计 | 基于预测关键点生成横纵跨度、包围盒对角线、面积、比例、PCA 主次轴和角度正余弦等 9 维特征。 |
| 条件 GSD 回归 | 拼接 256 维图像特征、2 维类别概率、36 维姿态概率和 9 维几何统计，形成 303 维向量，通过 MLP 输出 `gsd_geo`。 |
| 横向尺度辅助分支 | 横向分辨率热图及其解码 GSD 参与辅助监督，不直接进入当前最终输出。 |
| 最终推理 | `geo_only` 选择 `gsd_geo` 为连续估计值，随后可映射为五档。 |


### 2. Source-GSD 留一尺度消融

为避免使用已冻结的 0.15 m/px 测试结果选择结构，分别留出四个训练源尺度，在其余源尺度上训练并在状态组隔离的留出数据上评价。六种配置保持统一的 303 维条件回归接口，输入消融采用对应特征置零，辅助监督消融去除对应损失。使用 seed42，共 4×6=24 组运行。

**表 4　消融实验 MAE（m/px）**

| 配置 | 0.10 插值 | 0.20 插值 | 0.05 外推 | 0.25 外推 |
|---|---:|---:|---:|---:|
| Full（本方法） | 0.020621 | 0.032682 | 0.043218 | 0.042122 |
| Pure image-only（移除全部结构条件输入） | 0.023092 | 0.030333 | **0.035828** | 0.044474 |
| No keypoint auxiliary | 0.020691 | **0.029595** | 0.043612 | 0.040536 |
| No panel statistics | 0.022642 | 0.030031 | 0.040833 | 0.042526 |
| No satellite/pose condition | **0.019669** | 0.031145 | 0.038621 | **0.035264** |
| No xres auxiliary | 0.020287 | 0.030504 | 0.045075 | 0.038504 |

**图 3.** 各消融配置相对于 Full 的 MAE 差值，负值代表该开发折误差更低。插值折和外推折单独展示，不计算混合总分。

在 0.10 插值折，完全移除类别、姿态及面板条件后，MAE 增加 0.002471 m/px，配对 Bootstrap 95% CI 为 [0.000924, 0.004026]，Holm 校正后 p=0.0070，表明结构条件整体对该尺度的估计有帮助。但 0.20 插值折的差异在多重比较校正后均不显著；边界两折 Full 的最近档准确率均为 0%，移除类别/姿态后 MAE 反而降低。说明条件信息的贡献依赖尺度位置，现有网络的边界外推仍有不足。本轮只完成单种子源尺度消融，不能将结果视为固定 0.15 上的模块贡献，也不用于替换已冻结模型。
